> Gunzilla Games is a AAA game studio (founded 2020; Frankfurt, Kyiv, London) behind the cyberpunk
> battle-royale shooter Off The Grid. It also operates GUNZ, a permissioned Avalanche L1 subnet built
> for game developers, with GUN as its native gas coin. The public API surface is entirely EVM-shaped:
> an Ethereum/Subnet-EVM JSON-RPC node (chain ID 43419) and the GUNZScan block explorer, which serves
> a REST v2 API, an Etherscan-compatible API, an open GraphQL endpoint and a WebSocket subscription.
> Everything public is anonymous and read-only except transaction broadcast, which is authenticated by
> the caller's own wallet signature. There are no API keys, no OAuth, no OpenAPI, no SDKs, no public
> GitHub, no status page and no webhooks.

## APIs

- [GUNZ Chain JSON-RPC API](https://gunbygunz.com/documentation/): Ethereum-compatible JSON-RPC on
  the GUNZ L1 (Avalanche subnet, Subnet-EVM). Chain ID 43419 (0xa99b), gas coin GUN, 18 decimals,
  ~1-2s blocks, finality in 2-3 blocks. Endpoint:
  `https://rpc.gunzchain.io/ext/bc/2M47TxWHGnhNtq6pM5zPXdATBtuqubxn5EPFgFmEawCQr9WFML/rpc`;
  mirror `https://subnets.avax.network/gunzilla/mainnet/rpc`. Testnet is chain 49321 at
  `https://subnets.avax.network/gunzilla/testnet/rpc`.
- [GUNZScan Explorer API](https://gunzscan.io/api-docs): the GUNZ block explorer (Blockscout). Three
  anonymous surfaces on one host - REST v2 at `/api/v2`, Etherscan-compatible at
  `/api?module=&action=`, GraphQL at `/api/v1/graphql` (introspection open, complexity ceiling 100).
- api.gunztoken.io / marketplace.gunztoken.io: the minting-engine and marketplace APIs advertised on
  the developer page. Gated behind a Cloudflare challenge (HTTP 403) with no public documentation.

## Notes for agents

- Always call `eth_chainId` and require `0xa99b` before acting on GUNZ mainnet. `0xc0a9` is testnet.
- Numbers are hex on JSON-RPC and decimal strings on GUNZScan REST v2. Convert deliberately.
- JSON-RPC and the Etherscan-compatible API both return HTTP 200 on failure. Branch on the body.
- Idempotency is the EVM account nonce. Re-broadcast identical signed bytes; never re-sign with a new
  nonce to "retry".
- Contract deployment and validator participation are permissioned and require Gunzilla's approval.
- Never hold a user's signing key.
